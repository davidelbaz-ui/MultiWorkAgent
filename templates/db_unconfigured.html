Common mistake

If the error mentions 127.0.0.1, you pasted your local DATABASE_URL into Vercel. Delete that variable on Vercel and use Storage → Postgres so POSTGRES_URL points to a remote host.

Vercel (production)

  1. Vercel project → Storage → create or connect Postgres.
  2. Ensure POSTGRES_URL or DATABASE_URL is set for Production (the integration usually adds this automatically).
  3. Redeploy after env vars change.

Format: postgresql://user:password@host:5432/dbname — password is part of the URL.

See docs/DATABASE.md in the repo for local Docker setup.
